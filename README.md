# p2a

A Rust library to generate efficient Arrow builders from `prost` structs at build time.

## How It Works

p2a reads provided prost code and generates a builder structs,
(e.g., `User` -> `UserBuilder`). This approach creates builder code for each of your
types at compile time.

This design comes with few key trade-offs:

*   **Runtime Performance vs. Compile Time**: The macro generates highly specialized code
for each struct. This gives excellent runtime performance because the compiler can inline
and optimize everything, but it will increase compile times.
*   **Developer Experience vs. Binary Size**: Because concrete builder types are generated,
you get great IDE autocompletion and type safety. The trade-off is that this generated code
can lead to a larger final binary.

## Generated API

The generated builder for a struct `T` (e.g., `User` -> `UserBuilder`) provides the following:

### Builder Methods
*   `TBuilder::default() -> Self`
*   `builder.append_value(&mut self, item: T)`
*   `builder.append_null(&mut self)`
*   `builder.append_option(&mut self, item: Option<T>)`
*   `builder.finish(&mut self) -> StructArray`
*   `builder.finish_cloned(&self) -> StructArray`

### Trait Implementations
*   `impl Debug for TBuilder`
*   `impl Default for TBuilder`
*   `impl Extend<Option<T>> for TBuilder`
*   `impl arrow::array::ArrayBuilder for TBuilder`

## Supported Types

| Protobuf Source | Rust (Prost) Type | Arrow Builder |
|-----------------|-----------|---------------|
| `bool` | `bool` | `BooleanBuilder` |
| `int32`, `sint32`, `sfixed32` | `i32` | `Int32Builder` |
| `int64`, `sint64`, `sfixed64` | `i64` | `Int64Builder` |
| `uint32`, `fixed32` | `u32` | `UInt32Builder` |
| `uint64`, `fixed64` | `u64` | `UInt64Builder` |
| `float` | `f32` | `Float32Builder` |
| `double` | `f64` | `Float64Builder` |
| `string` | `String` | `StringBuilder` |
| `bytes` | `Vec<u8>` | `BinaryBuilder` |
| `repeated` fields | `Vec<T>` | `ListBuilder<TBuilder>` |
| `optional` fields | `Option<T>` | `TBuilder` with `append_option` |
| `map` fields | `HashMap<K,V>` | `MapBuilder<KBuilder, VBuilder>` |
| `message` types | Custom structs | `{StructName}Builder` |
| `oneof` fields | Custom enums | `{EnumName}Builder` |

## Limitations

*   Structs that refer to each other in a cycle are not supported.
*   The macro is designed for structs generated by `prost` and
may not work on hand-written structs with incompatible types.
*   Fields inside a `Box<T>` are not yet supported.
*   Your project and `p2a` must use compatible versions of the `arrow` crate.
